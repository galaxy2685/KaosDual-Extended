# Using the WebUI

The Library page starts with six game buttons. Select a game to see its available elements and types. Search is live, partial, and case-insensitive; sorting and category controls work on metadata already returned to the browser.

Each library card provides **Load P1** through **Load P4** and raw **Download**. The four slot cards show which filenames are loaded and allow unloading without disturbing the other slots.

- **Favourites** toggles an entry’s favourite state.
- **User Added** shows runtime uploads and the upload control.
- **Rebuild Library** rescans library paths and regenerates metadata.
- **Delete** removes only an unloaded runtime entry; loaded files are protected.
- **Inspect** is available only where the editor can validate a supported normal figure.

After an in-game save, the normal writeback route updates the correct tracked slot file. Do not delete, edit, restore, or replace a loaded file—unload it first.
